### E-3 — Layouts — PASS with caveat

`layouts/Play.json` and `layouts/Debug.json` are valid JSON in the **SDK-canonical programmatic layout format**, generated by `foxglove.layouts` from the installed first-party `foxglove-sdk`. I verified against upstream `foxglove/foxglove-sdk@main` that the serializer emits exactly these `panelType` strings, including `"ThreeDee"` for the 3D panel — the files are not hand-rolled approximations.

- **Play** — Image (`/doom/camera`) + Teleop (`/cmd_vel`, 35 Hz, stop-on-release, tank controls) + Gauges for `/doom/player.health|armor|ammo`. Matches PLAN.
- **Debug** — adds ThreeDee (`/doom/map` colormap on `occupancy`, `/doom/entities`, `fixedFrame: map`, `followTf: base_link`), Plot (health + ammo vs timestamp), Log (`/doom/log`), RawMessages (`/doom/player`). Matches PLAN.

**Caveat (F-3):** import was not exercised in the actual Foxglove app GUI in this eval. The "importable" claim rests on the vendor's own serializer, which is strong but not demonstrated end-to-end.

### E-4 — Scope discipline — PASS
